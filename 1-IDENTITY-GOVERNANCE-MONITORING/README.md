# Module 1: Design Identity, Governance, and Monitoring Solutions (25-30%)

This module covers designing comprehensive identity, governance, and monitoring solutions for Azure, including authentication, authorization, compliance, and observability.

## 📖 Microsoft Official Documentation & Learn

### 1. Design Solutions for Logging and Monitoring
* **Microsoft Learn Path**: [Design solutions for logging and monitoring](https://learn.microsoft.com/en-us/training/modules/design-monitoring-strategy-on-azure/)
* **Key Topics**:
  * Recommend a logging solution
  * Recommend a solution for routing logs
  * Recommend a monitoring solution
  * Azure Monitor architecture and design
  * Log Analytics workspace design
  * Application Insights implementation

### 2. Design Authentication and Authorization Solutions
* **Microsoft Learn Path**: [Design authentication and authorization solutions](https://learn.microsoft.com/en-us/training/modules/design-identity-security-strategy/)
* **Key Topics**:
  * Recommend an authentication solution
  * Recommend an identity management solution
  * Recommend a solution for authorizing access to Azure resources
  * Recommend a solution for authorizing access to on-premises resources
  * Recommend a solution to manage secrets, certificates, and keys
  * Azure AD B2B and B2C considerations
  * Hybrid identity scenarios

### 3. Design Governance
* **Microsoft Learn Path**: [Design governance](https://learn.microsoft.com/en-us/training/modules/design-governance-strategy/)
* **Key Topics**:
  * Recommend a structure for management groups, subscriptions, and resource groups
  * Recommend a strategy for resource tagging
  * Recommend a solution for managing compliance
  * Recommend a solution for identity governance
  * Azure Policy design
  * Compliance and regulatory requirements
