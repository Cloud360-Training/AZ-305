# Module 2: Design Data Storage Solutions (20-25%)

This module covers designing comprehensive data storage solutions for relational, semi-structured, and unstructured data, including data integration and analysis.

## 📖 Microsoft Official Documentation & Learn

### 1. Design Data Storage Solutions for Relational Data
* **Microsoft Learn Path**: [Design data storage solutions for relational data](https://learn.microsoft.com/en-us/training/modules/design-data-storage-solution-for-relational-data/)
* **Key Topics**:
  * Recommend a solution for storing relational data
  * Recommend a database service tier and compute tier
  * Recommend a solution for database scalability
  * Recommend a solution for data protection
  * Azure SQL Database vs Managed Instance vs SQL Server on VM
  * Database replication and failover strategies

### 2. Design Data Storage Solutions for Semi-Structured and Unstructured Data
* **Microsoft Learn Path**: [Design data storage solutions for semi-structured and unstructured data](https://learn.microsoft.com/en-us/training/modules/design-data-storage-solution-for-semi-structured-data/)
* **Key Topics**:
  * Recommend a solution for storing semi-structured data
  * Recommend a solution for storing unstructured data
  * Recommend a data storage solution to balance features, performance, and costs
  * Recommend a data solution for protection and durability
  * Azure Blob Storage, Data Lake, Cosmos DB design
  * Data tiering and archival strategies

### 3. Design Data Integration
* **Microsoft Learn Path**: [Design data integration](https://learn.microsoft.com/en-us/training/modules/design-data-integration-solution/)
* **Key Topics**:
  * Recommend a solution for data integration

  * Data pipeline design and optimization
