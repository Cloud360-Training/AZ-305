# Hands-On Labs & Design Exercises

Practical experience in designing Azure solutions is essential for the AZ-305 exam, which focuses on architectural decision-making and solution design rather than hands-on implementation.

## 🧪 Microsoft Learn Sandbox

The Microsoft Learn Sandbox provides a free, temporary Azure environment where you can design and deploy solutions without needing a credit card.

### How to Access the Sandbox
1. Navigate to any Microsoft Learn module that includes a hands-on exercise.
2. Sign in with your Microsoft account.
3. Click the **Activate sandbox** button.
4. Review the permissions and accept.
5. You will have a set amount of time (usually 1-4 hours) to use the sandbox environment.

## 📝 Recommended Design Exercises

These exercises align with the AZ-305 exam objectives and provide practical experience with architectural decision-making.

### Design Exercise 1: Design an Identity and Access Management Solution
* **Objective**: Design a comprehensive identity solution for a hybrid organization.
* **Microsoft Learn Guide**: [Design identity and access management](https://learn.microsoft.com/en-us/training/modules/design-identity-security-strategy/)
* **Key Skills**: Azure AD design, hybrid identity, RBAC strategy, compliance requirements.

### Design Exercise 2: Design a Monitoring and Logging Solution
* **Objective**: Design an enterprise-scale monitoring solution with centralized logging.
* **Microsoft Learn Guide**: [Design monitoring strategy](https://learn.microsoft.com/en-us/training/modules/design-monitoring-strategy-on-azure/)
* **Key Skills**: Azure Monitor architecture, Log Analytics workspace design, alerting strategy.

### Design Exercise 3: Design a Data Storage Solution
* **Objective**: Design a multi-tier data storage architecture for a complex organization.
* **Microsoft Learn Guide**: [Design data storage solutions](https://learn.microsoft.com/en-us/training/modules/design-data-storage-solution-for-relational-data/)
* **Key Skills**: Database selection, scalability, replication, backup strategies.

### Design Exercise 4: Design a Business Continuity Solution
* **Objective**: Design backup and disaster recovery for critical workloads.
* **Microsoft Learn Guide**: [Design business continuity solutions](https://learn.microsoft.com/en-us/training/modules/design-solution-for-backup-disaster-recovery/)
* **Key Skills**: RTO/RPO calculations, failover strategies, multi-region design.

### Design Exercise 5: Design a Compute Architecture
* **Objective**: Design an appropriate compute solution for different workload types.
* **Microsoft Learn Guide**: [Design compute solutions](https://learn.microsoft.com/en-us/training/modules/design-compute-solution/)
* **Key Skills**: VM vs containers vs serverless, scaling strategies, cost optimization.

### Design Exercise 6: Design an Application Architecture
* **Objective**: Design a scalable, resilient application architecture.
* **Microsoft Learn Guide**: [Design application architecture](https://learn.microsoft.com/en-us/training/modules/design-application-architecture/)
* **Key Skills**: Messaging patterns, event-driven architecture, API design, caching strategies.

### Design Exercise 7: Design a Migration Strategy
* **Objective**: Design a migration plan for on-premises workloads to Azure.
* **Microsoft Learn Guide**: [Design migration solutions](https://learn.microsoft.com/en-us/training/modules/design-migration-solution/)
* **Key Skills**: Cloud Adoption Framework, workload assessment, IaaS vs PaaS decisions.

### Design Exercise 8: Design a Network Architecture
* **Objective**: Design a secure, optimized network infrastructure.
* **Microsoft Learn Guide**: [Design network solutions](https://learn.microsoft.com/en-us/training/modules/design-network-solution/)
* **Key Skills**: VNet design, hybrid connectivity, network security, load balancing.
