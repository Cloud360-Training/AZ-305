# Module 4: Design Infrastructure Solutions (30-35%)

This module covers designing comprehensive infrastructure solutions including compute, applications, migrations, and networking. This is the largest module and most critical for the exam.

## 📖 Microsoft Official Documentation & Learn

### 1. Design Compute Solutions
* **Microsoft Learn Path**: [Design compute solutions](https://learn.microsoft.com/en-us/training/modules/design-compute-solution/)
* **Key Topics**:
  * Specify components of a compute solution based on workload requirements
  * Recommend a virtual machine-based solution
  * Recommend a container-based solution
  * Recommend a serverless-based solution
  * Recommend a compute solution for batch processing
  * VM sizing and optimization
  * Container orchestration (AKS)
  * Azure Functions and Logic Apps

### 2. Design an Application Architecture
* **Microsoft Learn Path**: [Design an application architecture](https://learn.microsoft.com/en-us/training/modules/design-application-architecture/)
* **Key Topics**:
  * Recommend a messaging architecture
  * Recommend an event-driven architecture
  * Recommend a solution for API integration
  * Recommend a caching solution for applications
  * Recommend an application configuration management solution
  * Recommend an automated deployment solution for applications
  * Service Bus, Event Grid, Event Hubs design
  * API Management and integration patterns

### 3. Design Migrations
* **Microsoft Learn Path**: [Design migrations](https://learn.microsoft.com/en-us/training/modules/design-migration-solution/)
* **Key Topics**:
  * Evaluate a migration solution that leverages the Microsoft Cloud Adoption Framework for Azure
  * Evaluate on-premises servers, data, and applications for migration
  * Recommend a solution for migrating workloads to IaaS and PaaS
  * Recommend a solution for migrating databases
  * Recommend a solution for migrating unstructured data
  * Azure Migrate and Data Box
  * Lift-and-shift vs refactoring strategies

### 4. Design Network Solutions
* **Microsoft Learn Path**: [Design network solutions](https://learn.microsoft.com/en-us/training/modules/design-network-solution/)
* **Key Topics**:
  * Recommend a connectivity solution that connects Azure resources to the internet
  * Recommend a connectivity solution that connects Azure resources to on-premises networks
  * Recommend a solution to optimize network performance
  * Recommend a solution to optimize network security
  * Recommend a load-balancing and routing solution
  * ExpressRoute, VPN, and hybrid connectivity
  * Network architecture and segmentation
